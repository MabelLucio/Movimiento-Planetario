# Movimiento-Planetario
Distintos programas que describen órbitas planetarias gráficamente con métodos numéricos.
-------

### Primer programa:
El programa "Movimiento_planetario_1.py" calcula el movimiento y las trayectorias de los planetas Tierra y Júpiter alrededor del Sol (en reposo) considerando órbitas circulares coplanares. Se utiliza el método de Euler-Cromer y grafica:

![image](https://github.com/user-attachments/assets/5549265c-8317-408f-85d2-e478efe546ad)

### Segundo programa:
El programa "Movimiento_planetario_".py" muestra una animación del programa anterior se muestra el tiempo en años, la posición de cada cuerpo y la distancia entre éstos.
